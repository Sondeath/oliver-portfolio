# Oliver Libič — primary logo

`main-logo.png` is the approved primary logo, saved without changes from the
selected preview on 17 October 2026. It is a 1254 × 1254 opaque PNG with the
liquid purple O, Oliver Libič wordmark, and service line:

**WEB · E-SHOP · EVENTS · PRODUCTS**

The approved version applies an approximately 20% brightness reduction to the
whole original composition. It is not the earlier selectively darkened O.

`main-logo-384.webp` and `main-logo-768.webp` are optimized, resized copies for
the website. The full-resolution master is kept in Git and is not included in
the public build.

The header and mobile menu use a compact horizontal lockup: a CSS viewport of
the approved O plus live typography in the site's local Anton and Inter fonts.
The service line is omitted only on screens 360px wide or narrower. The
favicon embeds a small optimized copy of the approved image and displays the
same O through an SVG viewport; it is a raster-backed SVG, not a vector master.

The website keeps its existing hero and project artwork. Preview alternatives
in `output/logo-concepts/` are not primary brand assets or public build inputs.
