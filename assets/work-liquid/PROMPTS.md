# Obrazové podklady — built-in Image Gen

Všetky tri výstupy boli vytvorené vstavaným Image Gen, bez CLI a bez externého API kľúča. Transparentnosť oboch samostatných PNG je skutočný alfa kanál, overený po uložení. Finálne rozmery určil generátor; sú zaznamenané v README a manifeste.

## Upravený vizuál

Vstup: Oliverom priložený návrh 1, `codex-clipboard-4bee35f1-c7d6-43b7-af7f-a3dbaed60ace.png`.

Zadanie (skrátený záznam): Preserve exactly the chosen composition: huge white condensed 'Z NÁPADU DO REALITY.' upper left, two diagonally staggered black screen frames with authentic BeCool Shop screenshot upper right and BeCool corporate screenshot lower left, same project names/descriptors, bottom archive row. Change only purple atmospheric treatment: replace dry rocky purple backdrop with premium living liquid light, slow viscous ink in black space, organic lobes, soft bloom, pearlescent contours, translucent violet plumes. Palette #A879FF, #291440, #0B090F. Keep quiet negative space behind text and retain a subtle distressed O. Screenshots keep original colors. One 1536 × 1088 production-quality webpage mock, no added UI or claims.

Výstup: `refined-target.png`. Pôvodný súbor: `exec-59c2d1be-05e4-4604-a92b-fc849ba2ec01.png`.

## Liquid aura

Vstup: upravený vizuál vyššie.

Zadanie (skrátený záznam): Standalone transparent RGBA background effect asset, target 1536 × 1088. Output only organic violet living-liquid aura surrounding and linking two staggered display zones, upper-right x800..1450/y100..750 and lower-left x70..750/y500..950. Quiet transparent upper-left for heading. Remove all screens, devices, borders, websites, text, letters including O, logos, ground and UI. Natural uneven curls, low-frequency lobes, translucent iridescent violet ink, soft lilac edges and deep-purple wisps, silky viscous material. No splash droplets, sparkles, neon tubes, rectangular silhouettes or baked checkerboard. Generous transparent negative space. Intended for low-amplitude UV displacement behind actual project images.

Výstup: `assets/liquid-aura.png`. Pôvodný súbor: `exec-c16e8e7f-2330-40b4-82fd-25a37cb41cc3.png`.

## Odtlačok O

Vstup: pôvodný Oliverom potvrdený návrh 1.

Zadanie (skrátený záznam): Isolate/recreate only the large distressed purple O mark behind the displays as a separate true-transparent raster asset, target 1024 × 1024. One bold tall condensed oval O leaning clockwise 14 degrees, gritty ink print, worn scratches and ragged edges, #A879FF into #291440. Whole mark centered, transparent margins and worn gaps. No other letters, labels, screenshots, devices, liquid, scene, ground, backdrop or checkerboard. Quiet background motif, no chrome bevel or solid rock.

Výstup: `assets/odtlacok-o.png`. Pôvodný súbor: `exec-1577697a-67f0-459c-8d4f-a63714b76db5.png`.
